# 📝 测试卷专区

> **学完即测，输出倒逼输入** —— 这是费曼学习法最关键的闭环。

本目录存放全书配套测试卷，遵循"**每节一测 + 每章一测**"的原则。

---

## 🎯 使用指南

### 正确姿势（强烈建议）

1. **先做题，再看答案**：每份试卷有"题目版"和"答案解析版"两个文件，请务必先做题目版
2. **限时完成**：节末小测建议 20-30 分钟，章节综合卷建议 60-90 分钟
3. **对答案自省**：对照解析，不只改对错，更要**读懂"为什么错"**
4. **定位薄弱点**：解析文件开头的"考点分布表"能帮你快速定位薄弱环节
5. **回炉重读**：错题对应的知识点，回到正文用"费曼自测"重新讲一遍

### 试卷结构

| 类型 | 题量 | 用途 |
|------|------|------|
| **节末小测** | 8-10 题 | 学完一节立即巩固 |
| **章节综合卷** | 15-18 题 | 学完一章串联检验 |
| **挑战卷** | 8-10 题 | 高难度进阶（C9 期末压轴/CTF/安全认证难度） |
| **压力面问题** | 10-12 问 | 模拟大厂安全岗压力面试 |

### 题型分布

- **选择题**：概念理解 + 易混淆点辨析
- **判断/简答题**：直接考察核心防御原理
- **场景分析题**：给出攻击场景，要求分析并给出防御方案
- **面试追问**（压力面）：层层追问、质疑挑战、考察临场反应

## 📖 题目来源说明

所有题目参考以下来源进行**原创改编**，难度对标真实考试与面试：

1. **C9 高校试卷**：清华、北大、浙大、上交、复旦、南大、中科大、哈工大、西交大等高校《网络安全》《信息安全》课程
2. **大厂安全岗面试题**：字节跳动、腾讯、阿里巴巴、百度、华为等安全岗面试真题
3. **易混淆知识点**：加密 vs 编码、认证 vs 授权、IDS vs IPS、对称 vs 非对称、漏洞 vs 威胁 vs 风险
4. **高频易错点**：新手最常踩的坑（如"HTTPS 就绝对安全""用 MD5 存口令""防火墙能防一切"）
